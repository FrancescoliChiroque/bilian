# BILIAN Lily Palacios

Landing page de alta conversión para BILIAN, diseño de moda femenina de autor. Objetivo: agendar citas para diseños personalizados vía WhatsApp.

## Estructura

```
.
├── index.html          # Estructura de la página
├── css/styles.css      # Estilos (paleta "Atardecer Etéreo")
├── js/main.js          # Preloader, menú móvil, acordeón y visor de fotos
├── img/                # Logo, fotos de diseñadora y colecciones
│   ├── Coctel/
│   ├── Diario/
│   ├── Diseñadora/
│   └── Novias/
└── netlify.toml        # Configuración de despliegue
```

## Despliegue en Netlify → bilian.site

1. Sube este repositorio a GitHub.
2. En Netlify: **Add new site → Import an existing project → GitHub**.
3. Selecciona el repositorio. `netlify.toml` ya indica la raíz como carpeta de publicación, no hace falta configurar nada.
4. **Deploy**.
5. Para usar `bilian.site`: **Site settings → Change site name → `bilian`** (quedaría `bilian.netlify.app`, ya que `.site` requiere dominio personalizado) o añade tu dominio en **Domain settings**.

> Nota: los enlaces son relativos, por lo que la página funciona igual en local y en producción, sin cambios.
